# DanceSequenceAutomaticEncoding
此子計畫以既有的舞蹈骨架資料為輸入，透過動作序列編碼演算法，將關節位置與時間變化轉換為具語意的文字符號，過程使舞蹈動作可被語言化與結構化，用以分析、標註或生成具敘事性的舞蹈描述。
